# Cinefly — Identidade Visual

## Marca
- **Nome:** Cinefly
- **Slogan:** Decole no universo do cinema
- **Tagline secundária:** Filmes, séries e documentários em um só voo
- **Conceito:** Cinema + voo — descoberta sem fronteiras, experiência sofisticada e imersiva

## Logo
| Arquivo | Uso |
|---------|-----|
| `assets/logo.svg` | Logo completa (marca + wordmark) |
| `assets/logo-mark.svg` | Ícone / app / favicon grande |
| `assets/favicon.svg` | Favicon do navegador |

## Tipografia
| Papel | Família | Uso |
|-------|---------|-----|
| Display / Marca | **Syne** (700–800) | Logo, hero, títulos de seção |
| Interface / Corpo | **Manrope** (400–600) | Nav, formulários, sinopses, botões |

## Paleta
| Token | Hex | Função |
|-------|-----|--------|
| `--ink` | `#0B0F14` | Fundo principal (tela de cinema) |
| `--surface` | `#141A22` | Painéis, modais, cards de formulário |
| `--surface-2` | `#1C2430` | Hover / elevação |
| `--amber` | `#E8A838` | Acento principal (spotlight) |
| `--amber-light` | `#F0C14B` | Destaques e hover |
| `--teal` | `#2DD4BF` | Acento secundário (voo / inovação) |
| `--cream` | `#F5F0E8` | Texto principal |
| `--muted` | `#8B95A5` | Texto secundário |
| `--danger` | `#E85D5D` | Erros / remover |
| `--success` | `#3ECF8E` | Sucesso / confirmação |

## Gradientes
- **Hero:** `linear-gradient(135deg, #0B0F14 0%, #1A1520 40%, #0E1A1C 100%)` + wash âmbar/teal
- **CTA:** `linear-gradient(135deg, #E8A838, #F0C14B)`
- **Accent line:** `linear-gradient(90deg, #E8A838, #2DD4BF)`

## Sensibilidade
- Atmosfera de sala de cinema: escuro, quente, elegante
- Posters e arte carregam a cor; UI permanece sóbria
- Âmbar = ação / play; Teal = descoberta / voo
- Motion suave: fade-up, slide de carrosséis, hover scale em posters
